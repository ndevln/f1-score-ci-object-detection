# Stan fits of the pathologist design

The Stan fits of step 04_1 (`04_1_fit_models_pathologists.Rmd`, about 1.7 GB) are too large for
this repository and are not shared. The later steps do not need them, since their estimates (`estimates_pathologists/`) and
the evaluation data (`S3_Data_*`) are included. This folder only contains the sampler settings and
the diagnostics of all fits.
