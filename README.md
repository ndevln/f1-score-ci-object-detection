# Confidence intervals for the F1-score in medical object detection

Code and data of the paper "Confidence intervals for the F1-score in medical object detection:
comparing bootstrap and Bayesian multilevel methods" (under review). The supplements S1-S4 are
provided as R Markdown files with their rendered PDFs and data, and the folder `simulation/` contains
the code of the simulation study. Code is licensed under the MIT license (`LICENSE`), data under
CC BY 4.0.
